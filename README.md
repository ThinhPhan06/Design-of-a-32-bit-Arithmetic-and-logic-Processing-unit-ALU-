# Design-of-a-32-bit-Arithmetic-and-logic-Processing-unit-ALU-
_Designed, integrated, and verified a 32-bit Arithmetic Logic Unit (ALU) for the Beta CPU architecture. The ALU accepts two 32-bit operands and executes multiple groups of operations based on the control code ALUFN[5:0].
The objective is to implement a 32-bit ALU capable of performing:
Arithmetic operations: addition, subtraction.
Logic operations: AND, OR, XOR, LDR.
Shift operations: logical shift left, logical shift right, arithmetic shift right.
32-bit multiplication.
Comparison operations: equal, less than, less than or equal.
The design was fully verified via simulation to ensure functional correctness of output results and status flags_
